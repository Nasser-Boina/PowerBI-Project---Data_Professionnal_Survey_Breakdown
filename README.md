# Introduction

In this project, as a Data Analyst at a leading global IT consulting firm, I was tasked with analyzing the latest technology trends to identify the most in-demand skills for 2025. Drawing insights from job postings, training platforms, and the Stack Overflow Developer Survey, the objective was to transform raw data into clear, actionable information to support strategic workforce planning.

The results of this analysis were presented in a comprehensive **PowerPoint presentation**, which synthesizes all key insights and visualizations.

## Background
The technology sector evolves rapidly, and staying ahead requires a deep understanding of current and future skill demands. The goal of this initiative was to gather, analyze, and highlight key trends in programming languages, database technologies, and development environments most sought after in today's market.

Data sources included public APIs for job postings and the official Stack Overflow Developer Survey. After consolidating and preparing the data, the focus was placed on uncovering meaningful insights to inform hiring strategies, training investments, and career development programs.

# Key Findings

All findings are detailed and illustrated in the [DataAnalystPresentation.pdf](DataAnalystPresentation.pdf) attached to the project. Here’s a summary of the main trends identified:

## 1. Most In-Demand Programming Languages
- Python leads the demand for its applications in AI, data science, and backend development.

- JavaScript is critical for full-stack and frontend development.

- SQL remains essential for data management and analytics roles.

## 2. Most Sought-After Database Technologies
- MySQL and PostgreSQL dominate the relational database space.

- MongoDB stands out among NoSQL databases for its flexibility.

## 3. Most Popular Integrated Development Environments (IDEs)
- Visual Studio Code is by far the most popular IDE across developers.

- IntelliJ IDEA and PyCharm are highly appreciated among Java and Python developers, respectively.
